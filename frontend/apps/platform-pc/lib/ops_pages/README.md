# ops_pages（运营后台）

按左侧菜单一个板块一个目录，目录名与板块名一一对应，方便定位每个板块下的页面：

| 目录 | 内容 |
| --- | --- |
| `租户/` | 租户列表、成员管理、开户审核、租户设置 |
| `团队空间/` | 租户团队、团队设置 |
| `项目/` | 租户项目、项目设置、订阅计费、开通/变更/退订审核 |
| `API授权/` | API Token |

- `operations_console_dialog.dart`：运营后台入口弹窗（根目录）。
- `operations_sidebar.dart`：左侧树形菜单（板块 → 页面）。
- `operations_action_dialog.dart`：内容区内嵌动作面板工具，供各板块页面复用。
- `operations_preview.dart`：未接入业务页的菜单项回退到原型预览。
- 各目录下与页面同名的 `.dart` 原型页（如 `租户/租户列表.dart`）为原
  Mockplus 转换产物，仅原型预览用，业务页接入后按需删除。

个人资料 / 账号安全 / 多因素认证 / 本地化 已独立为 `personal_pages`，
由平台端顶栏账号菜单进入，不再作为运营后台的板块。
