# admin_pages（系统管理）

按左侧菜单一个模块一个目录，**模块 = `<name>_model`**，**页面 = `<name>_page` 文件夹**，
页面默认文件为 `index.dart`，便于按菜单定位模块、按页面归档其弹窗/子组件。

| 模块目录 | 内容 |
| --- | --- |
| `settings_module/` | 通用、本地化、电子邮件、编码规则、短信、auth登录、验证消息 |
| `users_module/` | 用户、角色 |
| `permissions_module/` | 权限 |
| `menus_module/` | 菜单 |
| `basic_module/` | 世界地理规划、地区&国家、导入地区、UTC、时区数据库、货币、历史汇率 |
| `localization_module/` | 多语言、翻译、导入、导出 |
| `logs_module/` | 验证、操作、登录、支付日志 |

## 命名约定

- 模块文件夹：`<name>_module/`
- 页面文件夹：`<name>_page/`，页面主文件固定为 `index.dart`（页面组件在 `index.dart` 中）
- 页面子组件/弹窗随页面归档在其文件夹内，弹窗按语义选后缀：
  `_modal.dart`（面板/叠加层，`showSystemSettingsPanel` 类）、`_dialog.dart`（确认框）、
  `_sheet.dart`（底部弹层）、`_toast.dart`（瞬时提示）
- 数据模型文件：`<name>_models.dart`（复数），与模块 `_model`（文件夹）、面板 `_modal` 区分
- 跨模块复用组件统一放 `shared/`，页面间优先用 `package:ruoqi_platform_pc/admin_pages/...` 绝对路径引用

## 目录结构

- `system_settings_dialog.dart`：系统管理入口弹窗（根目录）。
- `settings_content_dialog.dart`：内容区内嵌面板工具，供各菜单页面复用。
- `shared/`：跨模块复用的表格/状态徽章/用户管理组件（`table_card`、`status_badge`、
  `user_management_widgets`、`user_management_models`）。

原 Mockplus 转换产物（`Generated by tools/rp2flutter/convert.py`）已随业务页接入完成后移除；
`prototype_registry.dart` 中的管理后台原型条目一并清理，仅保留 ops_pages 原型预览。

七个菜单均已接入规范业务页（`DESIGN-consensus.md`）；页面内容按原型提炼，交互
（表格 / 筛选 / 弹层面板 / 状态徽章）复用 `shared/` 下组件。
