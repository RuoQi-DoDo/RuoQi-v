# 平台账号中心小程序

原独立平台 App 的个人中心原型已收敛到业务 App 的“平台管理”小程序。
入口位于客户首页上拉后的小程序选择页。

## 目录

- `platform_mini_program.dart`：小程序生命周期、路由和本地账号状态入口。
- `platform_models.dart`：资料、第三方关联、设备和日志的本地状态。
- `platform_style.dart` / `platform_widgets.dart`：小程序页面共用的间距、卡片、
  列表项、表单和按钮。
- `pages/`：账号中心、个人资料、账号安全、手机/邮箱绑定、密码修改、
  第三方关联、设备管理和账号日志。

## 样式约定

- 页面使用语义化 Flutter 布局与可滚动列表，不沿用绝对定位的原型画板。
- 页面间距统一为 16，卡片圆角 16，表单和按钮圆角 14。
- 颜色优先使用当前 `ColorScheme`，支持亮色和暗色主题。
- 原生状态栏、小程序标题栏、半透明公共胶囊菜单和上滑退出由
  `MiniProgramShell` 提供。

当前绑定、验证、解绑和设备下线均为可交互的本地模拟流程；平台域 API 客户端位于
`lib/api/platform/`，后续接入真实接口时可替换控制器中的本地操作。
